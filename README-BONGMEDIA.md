# Bống Media — Nioland HTML template (Vietnamese demo)

This is a static HTML build based on the supplied Nioland template source. The original layout, CSS, JavaScript, and assets are retained; the business-solutions page is used as the home page and common interface copy has been localized to Vietnamese. Open Sans is loaded for Vietnamese typography.
